# Termite releases

Downloads for **Termite**, the macOS terminal where tabs live in a sidebar: named, colour-tagged and one keystroke away.

**[Download the latest Termite for Mac](https://github.com/frimpongopoku/termite-releases/releases/latest/download/Termite.dmg)** · macOS 15 or later · Apple Silicon & Intel

Website: https://termite-174fd.web.app

This repository only holds the installers. Open the DMG and drag Termite into Applications. Early builds aren't notarized yet, so the first time you open Termite, go to System Settings → Privacy & Security and click **Open Anyway**.
